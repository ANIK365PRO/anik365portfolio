# Anik365 Portfolio

A modern, responsive personal portfolio built with **Next.js, React, Tailwind CSS, and GSAP**.

## 🚀 Tech Stack

* Next.js 16
* React 19
* Tailwind CSS 4
* HeroUI
* GSAP
* Framer Motion
* Lenis
* Lucide React

## ✨ Features

* Responsive design
* Smooth scrolling
* Modern animations
* Dark/Light mode
* Project showcase
* Skills & experience
* Contact section

## 🛠️ Installation

```bash
git clone https://github.com/your-username/anik365protfolio.git
cd anik365protfolio
npm install
npm run dev
```

Open `https://anik365portfolio.vercel.app` in your browser.

## 📦 Build

```bash
npm run build
npm start
```
